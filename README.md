# Zelunavo · Monatsbüro

Öffentliche Vorführdemo für einen nachvollziehbaren, nutzerkontrollierten Monatsworkflow. Das Demo-Paket enthält ausschließlich fiktive Unterlagen und Beispieldaten.

- [Projekt-Highlights und Entwicklung](Timeline_Gesamtprojekt_Zelunavo.html)
- [Fiktives Demo-Paket als ZIP herunterladen](Zelunavo-Demo-Paket.zip)
- [Sicherheitscheck der Demoversion](SICHERHEITSCHECK_DEMOMODUS.md)

Nach dem Herunterladen das ZIP entpacken und die enthaltene `github-upload/README.md` öffnen. Dort stehen Demoablauf, Startmöglichkeiten und die enthaltenen fiktiven Monatsfälle. Es wurden keine Gmail- oder Vendon-Zugangsdaten, echten Kontoauszüge oder Arbeitsunterlagen veröffentlicht.
